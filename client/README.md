# eFOT Frontend

React + TypeScript + Material UI + Recharts.

The application is organized around a protected analytics workspace:

- dashboard KPI layer;
- smart scenarios and anomaly signals;
- server-side search/filter/pagination;
- drill-down to detailed company/activity data;
- administrator Excel import with automatic dataset detection;
- PDF reporting;
- profile and user administration.

Set `REACT_APP_API_URL` if the backend is not running at `http://localhost:5000/api`.
